# 页面 UI 设计与生成工程 (20260814-page-ui-design)

本项目是一个专注于 **前端 UI 页面设计推导与提示词生成** 的智能化辅助工程。项目内置了特定的 AI Agent 技能（Skills），能够基于《逻辑资产说明书》自动推导 UI 页面清单，并将具体的页面需求拆解为可供 AI 设计工具（如代码生成、UI生成工具）直接使用的高质量结构化提示词。

## 目录结构

- `.agents/`：包含 AI 智能体配置与专属技能。
  - `AGENTS.md`：定义了本工程特定的 AI 智能体规则（例如：严格的文档版本控制和变更追溯规范）。
  - `skills/`：AI 专属能力目录。
    - `page-list-generate/`：自动推导页面清单与关联业务操作。
    - `page-to-prompt-generate/`：自动拆解页面，生成高质量结构化的 UI 生成提示词。
- `docs/`：存放相关需求说明书、生成的 UI 页面清单以及输出的提示词文档。

## 核心工作流

1. **页面推导 (Page List Generation)**：
   将《逻辑资产说明书》提供给 AI，通过调用 `page-list-generate` 技能，自动完成业务降维，输出精准的前端 UI 页面清单及对应的业务操作。
2. **提示词生成 (Page to Prompt Generation)**：
   基于生成的《UI页面清单》与原说明书，通过调用 `page-to-prompt-generate` 技能，针对指定的页面，自动拼装输出高质量的“结构化 UI 生成提示词”。

## 规范要求

根据项目规则，在生成或修改 `docs/` 目录下的需求、设计等相关文档时，必须遵守以下规范：
- **禁止原地覆盖**，必须创建新的版本文件（如追加 `_v2` 等）。
- **必须记录变更履历**，文档头部必须包含修改日期、修改执行人及核心变更点。
*(注：`.agents/` 目录下的配置文件及技能脚本不受此版本追溯规则限制。)*
